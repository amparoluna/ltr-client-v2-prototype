# Agents

This repository is a small software factory and the LTR V2 client prototype it produces.

Read these before any change:

1. [factory/scope.md](factory/scope.md) — what the prototype includes, in slice order
2. [factory/architecture.md](factory/architecture.md) — the pieces and how they connect
3. [factory/production-plan.md](factory/production-plan.md) — the steps for building one slice

Work one slice at a time, by the production plan. Product code lives in `app/`. Factory files live in `factory/`. `local-resources/` is the Driver's local notes; do not read or change it unless asked.
